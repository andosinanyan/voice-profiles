          How recognition works

          1. Speechsplit at pauses
          2. Voiceprint256 numbers per phrase
          3. Groupphrases into speakers
          4. Matchsaved voices, same workspace
          5. Nameonly when clearly sure

          Not sure? It stays "Speaker N". Better unnamed than wrongly named.

          Consent

          • The person agrees, never the host
          • A voiceprint, not a recording
          • Delete any time, instantly

          Accuracy

          • A score on every line
          • Mark lines ✓ or ✗ to measure
          • Production: labeled test set per device

          Separation

          • One database per customer
          • Own AES-256 key, not exportable
          • Compared only within a workspace
